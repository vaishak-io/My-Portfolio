A production-ready, ultra-clean, minimalist portfolio website inspired by the dark-mode aesthetic of the **csume-v3** Framer design language. Tailored for **Vaishak S** — Cyber Security Analyst specializing in SOC Operations, Blue Team Defense, Threat Detection, and VAPT.

---

## ⚡ Key Highlights & Features

- **Cybersecurity & Blue Team Aesthetics**: Deep slate/near-black theme (`#09090b`), ambient top emerald radial glow, and refined micro-interactions.
- **Interactive SOC Shell (`Alt + T` or `~`)**: Built-in in-browser Kali Linux-style terminal supporting commands like `whoami`, `status`, `skills`, `projects`, `resume`, `contact`, and `matrix`.
- **Bento-Grid Security Labs**: High-density operational testbeds with live architecture badges and simulated operational telemetry logs:
  - **Raspberry Pi Pentest & Auditing Workstation** (Headless ARM Linux, 802.11 monitor mode/injection)
  - **SOC Event Investigation & Threat Detection Lab** (Wazuh/Elastic SIEM, Suricata NIDS, MITRE ATT&CK correlation)
  - **Automated Vulnerability Assessment Pipeline** (Python & Bash automation with Nmap NSE and CVE correlation)
- **Technical Arsenal Matrix**: Categorized proficiencies across Defensive/SOC, Offensive Security/VAPT, Security Tooling, and Platforms/Scripting with hover focus tooltips.
- **In-Browser Resume / CV Dossier**: Dedicated printable executive resume view (`window.print()` / PDF export).
- **One-Click Actions**: Instant clipboard copy with celebratory micro-confetti feedback.
- **Live Local Time**: Dynamic Indian Standard Time (IST, Trivandrum) real-time clock.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18+ recommended) installed.

### Installation

```bash
# Clone the repository
git clone https://github.com/vaishak-io/My-Portfolio.git

# Navigate into the project folder
cd My-Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
npm run preview
```
